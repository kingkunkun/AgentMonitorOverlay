# 合作模式、隐私与局域网手机连接

本 fork 用户在 2026-11-10 确定的实现。顶栏只有“合作模式”入口；书签功能关闭但历史数据保留。账号、远程与中转分别操作，不需要同时打开。弹窗的“收起窗口”只是收起界面。

## 开关和账号

- “关闭远程”：停止设备通道，不能通过远程继续发消息、读取任务或下指令；配对与授权记录保留，重启保持关闭。
- “关闭中转”：停止 Host 中转轮询与客户端连接；独立于远程。接收中转聊天不等于授权远程访问任务。
- “一键关闭合作模式并退出账号”：先断开远程/中转，再退出共享账号并停止本机手机服务。已经提交给 Jenkins 的构建不取消；本机正在执行的模型任务也不会被终止。
- 账号复用 `%APPDATA%/AMO/account.json`，凭据按 Windows 用户加密。WorkStudio 与平台共用该账号，退出也会影响平台登录。不同服务器的账号互不通用，目前一次只登录一个服务器，未实现个人服务器和公司服务器的双账号桥接。
- 退出后保留最近使用的服务器地址并自动回填，也可点“最近使用”选回；登录只需输入账号、密码。登录不会重新开启远程/中转。如果选择的是已经停止的本机手机服务，需要先点“启动手机服务”。

## 手机连接步骤

1. 电脑打开合作模式，启动“自己的手机服务”，点击“允许局域网连接”。初始只监听 `127.0.0.1:47950`，未允许 LAN 时手机不能连接。
2. 退出原来的团队账号，点击“使用自己的服务登录”，用本机显示的注册邀请码创建账号，密码至少 12 位。
3. 手机安装本机编译的调试 APK，填写电脑显示的局域网地址（例如 `http://192.168.1.10:47950`），登录刚创建的同一个账号。手机不要填写自己的 `127.0.0.1`。
4. 电脑开启远程，手机从在线设备里选择电脑申请配对，在电脑确认。可逐任务授权；或者明确勾选“同账号设备…同步所有本地任务及新任务”。此项会共享任务完整聊天，默认不开；关闭勾选不会撤回已经发出的任务授权，应另在远程页面收回。
5. 手机收发消息、审批、回答问题、选择模型/思考强度/权限，执行仍在电脑。模型选项由对应 CLI 实际能力决定。中转收件会映射成本地待办，消息本身不自动启动模型；手机在任务会话继续发送后才执行。

同一可达局域网不需要 Tailscale。Wi-Fi 的访客隔离、公司网络 ACL 或 Windows 防火墙可能阻止 47950；本次没有修改公司网络或自动添加防火墙放行。没有公网入口时，5G 不能直接连公司内网电脑。本次只完成局域网方案。

本机服务复用 Relay 账号/设备协议，数据在 Studio 数据目录旁的 `phone-server/`；原 `.data` 与已有中转数据均保留。Android 工程在 `mobile/`，APK 是内部调试签名，真实手机未验收。iOS 源码存在，IPA 未在 Windows 编译/签名。

## 隐私边界

已关闭原生 Claude 会话列表、预览、接续导入，删除 runtime 的原生历史导入实现；Codex 只使用 Studio 数据库已有的会话引用，不新增原生历史导入。带有旧 `claude-adopted:*` 导入标记的任务不能远程授权或走 AI 中转。工作台自己的会话、分支及子代理日志仍会被读取，以恢复其任务；模型登录/额度功能也仍使用用户配置的模型凭据，这与导入原生历史不同。

Host 远程文件读取及 Review 内容外发需要电脑弹窗批准；分块仅在同一文件/接收方短期批准内继续，撤回授权或关闭远程后再检查。已知原生客户端私有目录禁止发送，解析符号链接后检查。中转 AI 发问/追问固定等待人点发送；集成中转窗口手动上传也有原生确认框。模型的自动审批/全部允许不关闭这些应用内规则。

未发现新增全局键盘记录或剪贴板读取监听；用户主动粘贴仍属于输入动作。剪贴板复制功能仍保留。旧独立中转程序与外部 CLI 配置已移到可恢复的停用备份目录，用户数据未删除；没有改写 `.codex` 或 `.claude` 的历史/配置。

这不是操作系统隔离。获不受限 shell 权限的模型或用户自行配置的 MCP 仍可能读取任意可访问文件或联网；应用层路径检查不能识别人为复制、改名或粘贴的原生对话。若要“即使全部允许也绝对不能外发”，还需要独立 Windows 用户/沙箱与网络策略。不能把本次检查描述为零漏洞或绝不泄露的证明。

远程/中转协议目前信任所选服务器，并非端到端加密；服务器可见经过它的聊天/附件。LAN 的 HTTP 流量没有 TLS 加密，应仅连接可信服务与可信局域网。收回授权不会抹除对方此前已经同步的数据。

## 验证

使用隔离的临时账号和本机模拟服务验证开关、同账号任务同步、原生导入拒绝、外发确认、旧书签数据保留及模型工具关闭。Playwright 验证合作模式、集成中转开关与打包入口。Android APK 本机编译通过；没有向真实团队成员发送测试消息，也没有使用真实 Jenkins 触发测试构建。完整测试中的已有模型/DSH 负载超时在单独重跑通过，不能宣称全量套件第一次运行全绿。
