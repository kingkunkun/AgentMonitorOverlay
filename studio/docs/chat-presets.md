# 本地 # 提示词与聊天界面

顶栏和聊天输入框的“# 提示词”，以及“设置 → # 提示词”，都可以管理预设。每条预设包含名称、默认聊天任务和自动动作；动作只能是普通聊天、固定 iOS Job 或固定安卓 Job。选择预设只填入草稿，点击发送才执行。

预设保存在 Studio 数据目录的 `chat-presets.json`；本机开发版是 `D:\Codex\AgentMonitorOverlay\studio\.data\chat-presets.json`。首次打开自动写入两条默认打包预设。设置界面显示实际文件路径，可增删、修改并保存；重启保留，不随 Git 提交。手工编辑请保持合法 JSON，格式损坏会报错而不会覆盖。

```json
{
  "version": 1,
  "presets": [
    {
      "id": "build-ios",
      "phrase": "高配打包机 自动出IOS包",
      "prompt": "生成 iOS 包，在本聊天报告结果，失败时分析日志。不要自动重复提交。",
      "job": "ios"
    },
    {
      "id": "explain",
      "phrase": "解释代码",
      "prompt": "解释当前问题涉及的代码及调用链，并给出相关文件位置。",
      "job": null
    }
  ]
}
```

发送时第一行必须精确为 `#名称`，下一行可以继续补充任务。只有绑定已批准 Job 的预设会被 Host 拦截执行；不会根据任意 URL 或自然语言执行 shell。打包结果、失败日志和模型分析见 [打包说明](build-job.md)。

## 桌面与手机

- 默认使用“Codex”浅色主题；设置中可改为系统、浅色或深色。专题与画布默认隐藏，设置 → 界面可恢复，数据保留。
- 点击项目显示看板并展开聊天；项目菜单支持置顶、新聊天、编辑、分区、打开资源管理器、归档聊天、从侧栏移除。移除项目只隐藏入口，不删除目录和任务。
- 聊天菜单支持置顶、改名、归档；桌面支持 Ctrl 多选后批量置顶或归档，聊天页标题也可改名。归档保留记录，会停止该任务正在运行的会话。
- 新聊天不要求名称或专题，保留项目选择、模型、思考强度和权限。标题从首句话生成，旧草稿被新聊天替换前会在本机保留一份。
- 手机 Android/iOS 共用 `mobile/shared` 的主题、项目分组、聊天置顶/改名/归档、新聊天和 # 预设界面；电脑完成配对与任务授权后使用。置顶及主题按各设备保存，不跨设备同步；改名/归档会修改电脑上的同一任务，其他账号不能归档整个任务。

Windows 上仅验证 Android APK 编译。iOS 代码已同步，但 IPA 构建、签名及真机布局仍需 Mac/iPhone 验证。

## 输入框与正文样式

会话输入框左侧保留 # 提示词、附件、权限与“＋”菜单，右侧是模型/思考强度和发送或停止。点击模型打开强度浮层：滑块、分级点或方向键调整强度，点击模型名进入按渠道分组、可搜索的全部可用型号列表。权限、工具和模型各自展开，点击外部或 Escape 收起。

Fast 开启时在输入框右侧常驻闪电图标，可直接点击关闭；浮层显示渠道提供的速度/计费说明，以及缓存的账号额度。只有接口明确提供 Fast 窗口时才标为“Fast 剩余”；普通订阅窗口标为“当前账号剩余”，未提供独立 Fast 数据时明确说明，不推算百分比。

同一渠道直接更换型号；跨渠道必须等当前回复、审批和循环结束。选择其他渠道时，在同一任务下创建接续会话，不启动模型回复，不改写原会话，并移动未发送草稿。下一条消息才把当前 WorkStudio 聊天的用户文字和 AI 回答交给目标渠道，输入框中可展开查看携带内容。只携带最近最多 200 条、60000 字符；超长会明确提示截断。附件、工具输出和原生客户端记录不随历史自动外发。连续切换会继续携带已接续的文本，避免嵌套重复的包装。

跨渠道使用目标渠道自己的权限默认值，兼容的思考强度可保留，Fast 默认关闭；模型和权限随后仍可调整。原会话可从同一任务的会话列表回看。自己的已配对手机可在授权模型范围内接续；其他账号不能切换渠道读取历史。

完全访问仍遵守既有文件外发确认规则。生成中的排队或插话行为保持原样，停止按钮始终可用；没有待发送内容时只显示停止，不并排显示不可用的发送按钮。

Codex 主题使用无衬线正文，15px 字号和更宽松的行距、段落/列表间距，代码保持等宽字体。改动只影响渲染，不重写历史消息。手机共用界面同步输入框分组、型号列表、强度滑块及正文样式；手机选项点击“应用”后由电脑验证，取消不会提交。跨渠道成功后可进一步调整强度与 Fast。

主界面统一使用“全部聊天”“Focus”“搜索聊天记录”，移除标题栏左右历史箭头，原有键盘导航仍保留。搜索仍按聊天标题、会话名称、项目等信息匹配。
