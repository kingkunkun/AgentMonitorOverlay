# 手机与原生历史隐私检查（2026-11-11）

范围：本 fork 的 Host、Android/iOS 共用手机代码、Android 平台实现和清单。检查与加固不等于对所有依赖、服务器或外部模型进程作绝对安全证明。

## 允许的数据边界

只有 WorkStudio 自建聊天参与工作台恢复与授权同步。原生 Claude / ChatGPT / Codex / DOT 的原有聊天不得枚举、导入或转发；旧 `claude-adopted:*` 元数据及其后代分支也不能借新任务外发。用户提交的 WorkStudio 聊天会发送给其选择的模型服务，手机聊天操作通过用户登录的服务器传到电脑执行。

`runtime/claude/outside.ts` 已移除原生扫描和 SDK 调用，仅保留拒绝入口。`transcripts.ts` 在 SDK/文件探查前核对 Store 中自建引用、旧导入标记和父链，未知引用直接拒绝。原有 Claude 登录/额度读取仍用于用户配置的模型登录，不读取其原有会话正文。Codex 的正常恢复仅使用工作台已有引用；没有启用原生 thread/list 导入。ChatGPT/DOT 没有聊天扫描入口。

`core/cooperation.ts` 的任务转发检查沿父链拒绝旧原生导入；文件/Review 外发继续走电脑逐次确认，已知原生私有路径（含解析符号链接后的目标）直接拒绝。全部允许不免除这些应用内确认。

## 手机代码与权限

- Android 清单只声明网络、网络状态及安装自身更新所需权限；不申请相册、文件读取、通讯录、位置、短信、麦克风、摄像头、辅助功能或悬浮窗权限。合并 APK 权限另行核对。
- 未发现主动剪贴板读取、后台键盘/鼠标记录、相册/通讯录扫描、分析/广告 SDK 或手机文件上传实现。系统输入框接受用户自己输入或主动粘贴，系统键盘本身属于 Android/iOS 的信任范围。
- `PhonePrivacy.requireCommand` 限定已实现的 `rt.*` 任务协议，拒绝任意命令和非空/畸形 uploads；没有自动读取设备文件并附加到聊天的路径。
- HTTP 客户端不跟随重定向；不忽略 TLS 证书错误。下载更新限定已登录服务的更新路径并校验摘要，仍由用户启动系统安装器。
- HTML 查看器禁用 JavaScript；Android 还禁用网络、文件/Content 访问、持久化和新窗口；两平台使用 CSP 拒绝网络、脚本、框架、表单及 worker，不注册原生 JS 桥。静态 HTML 与样式保留，原有交互脚本不再执行。
- Desktop 的剪贴板入口是用户点击后的 `writeText` 复制，没有新增 `readText` 或全局键鼠监听。

## 归档、缓存与登录

Host 在任务列表、快照、按 ID 读历史和内容推送四处限制归档数据。归档通知只发 ID，不附正文；手机收到归档或撤销后删除状态和缓存。手机也过滤旧服务器快照，并在每页历史返回后重查有效性，避免迟到响应恢复已归档内容。

缓存使用版本 3 的活跃会话清单，只允许清单内会话读写；新版本清理旧版聊天缓存后重新同步未归档聊天。修订号和写锁避免旧异步写入复活已删除记录。电脑历史没有删除。离线手机在收到事件或下次刷新后清理，不能远程保证已卸载、断网或修改过的客户端立即清除副本。

账号与聊天缓存分开：Android 包名 `dev.amo.studio`、SharedPreferences `studio` / `chat-drafts`、Keystore 别名 `amo-studio-token` 保持。令牌用 AES-GCM + Android Keystore 加密；iOS 使用 Keychain。覆盖安装相同签名保留账号和草稿；主动退出、清除应用数据、卸载、服务器撤销/改密是例外。解密失败时不擅自删除旧凭据。禁用 Android 系统备份/设备迁移。

## 验证与限制

Host 相关测试通过（手机域、归档拒绝、原生拒绝、远程任务/文件、固定 Jenkins Job；最终包含 Claude 接续/移交和子代理入口的 47 项回归通过）。KMP 测试覆盖清单清理、迟到缓存写入、旧缓存迁移、命令与 uploads 拒绝、CSP。Android APK 和 androidTest 构建通过；`npm audit --omit=dev` 报告 0 个已知漏洞，此结果不能证明不存在未知漏洞。UI 测试只用 `.qa` 独立包与本机模拟账号，不接触正式手机账号和真实 Jenkins 构建。

MI 8 已覆盖安装 0.2.2 / build 6，升级前后正式包加密 account 值的摘要一致（未输出凭据）。实机 UI 自动化未能完成 Activity 启动，用户已明确选择手机稍后验证；未声称有通过的实机截图或 5G 验收。APK 权限清单与源码一致，额外只有 AndroidX 的应用私有动态广播签名权限。

LAN HTTP 本身无 TLS；当前所选服务器能够看到经过它的任务通信，并非端到端加密。5G 可使用两端同一 tailnet 的 Tailscale 加密网络通道，仍保留 WorkStudio 手机账号认证；未验证真实 5G 链路。

这些是应用层边界，不是 OS 沙箱。不受限的模型 shell、用户配置的 MCP、浏览器或其他进程依然拥有 Windows 用户原有的文件与网络权限；不能声称这些规则阻止它们任意读取/联网。若要求即使授予模型完全访问也无法越界，需另做独立 Windows 身份、受限执行环境和网络白名单。路径规则也不能识别人为复制、改名或粘贴的原生对话。
