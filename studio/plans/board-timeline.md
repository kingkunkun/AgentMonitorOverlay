# 看板：时间线、文件夹标识与「待审阅」不再堆积

> 状态：代码做完（2026-11-23），未编译发布。用户编译时一起生效。

2026-11-23 用户反馈：看板只显示当前项目的任务，找不到别的文件夹（例如 Codex 下的 project_ming_2）里刚做的事；任务做完后几乎都停在「待审阅」，要一个个找；卡片看不出任务在哪个文件夹。下面先写原因，再写新设计。

## 原因

1. **任务自动进「待审阅」，只能手动拖出来。** Host 的 `TaskService.watchColumns`（`host/src/features/tasks/service.ts`）监听会话：会话开始跑，任务从「待审阅」回到「进行中」；所有会话停下 `reviewSettleMs`（4 秒）后，任务移到「待审阅」。之后没有任何代码把它移走，只有人拖到「完成」。所以每做完一轮就多一张待审阅卡片，越积越多，新旧混在一起。
2. **看板跟着左侧选中的项目缩小范围。** `App.tsx` 点项目或聊天时会设工作区范围，看板按这个范围过滤，只剩当前文件夹的任务。别的文件夹刚完成的任务在看板上看不到。
3. **卡片不显示文件夹。** 卡片只在「全部」范围且开了专题时才显示专题名，没有文件夹名；没选项目时用的公共目录也没有名字。
4. **按列排，不按时间排。** 分列视图里每列各自排序，最新做完的任务不一定在最上面。

## 新设计

1. **默认时间线视图。** 所有文件夹的任务合在一个列表里，按最近活动时间从新到旧排，分成「今天」「昨天」「近 7 天」「更早」。最近活动取任务和它各会话中最晚的更新时间。原来的分列视图保留，标题栏有「时间线 / 分列」切换，选择记在本机（`amo.boardMode`）。
2. **文件夹栏。** 看板顶部列出有任务的文件夹及任务数，最近有活动的排前面；点一个只看这个文件夹，再点「全部文件夹」回来，选择记在本机（`amo.boardFolder`）。远程任务按所在电脑归为「远程 · 电脑名」，公共目录显示为「公共」。左侧选中项目不再缩小看板范围；专题范围照旧生效。
3. **快捷筛选**：「全部」「需要我处理」「进行中」「新完成未看」，记在本机（`amo.boardFilter`）。「需要我处理」= 等审批、提问、出错，或有待定决定，或新完成还没看过。
4. **每张卡片都标文件夹**，悬停显示完整路径或所在电脑。
5. **「新完成」标记。** 任务某次回复结束（或失败）后人还没点开看过，卡片上显示「新完成」，计法和 Focus 一致。点开看过就消失。
6. **待审阅一键「完成」。** 时间线里待审阅的行带「完成」按钮，看过就点，任务移到「完成」列，不用再拖。

自动进「待审阅」的规则不变：它仍然表示「做完了、等人看」。变的是找它的方式：按时间排在最前、带「新完成」标记、可以一键移走。

## 没做的

- 没有自动把待审阅移到完成。用户看没看过只有用户知道，自动移走会漏看。
- 归档任务列表按同一个文件夹筛选，其余不变。
