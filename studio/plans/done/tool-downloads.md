# 工具下载与本机安装

状态：做完（2026-11-13）。

用户要求在当前 WorkStudio 内提供不占主导航的工具下载入口，先放手机工作台 APK；提供可复制的下载链接，编译桌面与安卓并安装实机。明确授权重启，覆盖前面的暂不编译要求。

入口放在设置 → 工具下载，可启停本机服务、允许局域网、复制下载页和 APK 链接。默认关闭，数据在 Host 数据目录的 `tool-downloads/`，独立端口 47951，不扩大 Host 管理 API 的监听范围。

公开服务只读明确清单里的内容寻址 APK。发布脚本复制文件、计算 SHA-256、原子替换清单；服务核对文件大小和摘要，拒绝越界路径与指向目录外的链接。支持 HEAD、断点续传和浏览器下载页，页面转义内容。不提供上传、任意文件浏览、账号或聊天接口。

本机发布：`node scripts/tool-downloads.mjs publish <数据目录> <APK>`。启停在本机认证 API，下一次启动恢复开关。此服务不检查或安装工具更新；不接触团队服务器发布通道。

当前会话也运行在被更新的 Host 内，所以立即关闭会中断构建。独立的 `restart-studio-when-idle.mjs` 等待正式健康接口连续报告空闲，保存 SQLite 一致性备份，再请求不允许中断的正式退出。结束旧外壳后加载已编译源码，核对旧任务与会话 ID 均保留、公司工作台和下载服务可用，结果写到数据目录 `restart-after-build.json`。身份改变或任一步失败都停止，不强杀 Host。

验证：下载服务的文件隔离、摘要、HTML 转义、HEAD 和 Range；真实 Electron 设置页读取清单、开启/关闭；桌面编译/类型检查；Android 实机构建与安装。实机从登录页起步，不声称已验证手机账号登录或公司工作台的手机版页面。
