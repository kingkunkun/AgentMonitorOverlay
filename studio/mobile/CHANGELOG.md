# AMO Studio Android 改动说明

## 下一版

- Android 内部包 0.2.3 / build 7：包含 Android/iOS 共用的 Codex 风格模型、权限面板与旋转运行状态；由电脑“设置 → 工具下载”提供 APK 和下载页。沿用原包名与签名，覆盖安装保留账号和草稿。公司 Agent 管理与分活页面目前在桌面端。
- Android 内部包升级到 0.2.2 / build 6。包名、调试签名、账号偏好和 Keystore 别名保持，覆盖安装保留登录与草稿；无法解密时不擅自删除凭据。
- 点击聊天直接进入输入框；Codex 风格项目抽屉、聊天搜索、置顶和底部模型/权限选择面板。读取提示词和模型不再互相阻塞或弹出“上一项操作尚未完成”。
- 不下载归档聊天，归档/撤销后清理手机缓存；升级清理旧版聊天缓存后只重新同步未归档记录，不修改电脑历史。
- 手机协议只允许已实现的任务命令并拒绝设备文件上传；HTML 查看禁用 JavaScript、外部网络、文件访问及原生桥接，HTTP 不跟随重定向，不新增个人数据权限。
- 应用名改为 WorkStudio，Android/iOS 使用原创二次元女性头像；Android 内部包 0.2.1 / build 5。
- 登录说明改为本机独立手机账号；复用设备协议连接本机手机远程，支持电脑团队账号保持登录、团队远程关闭时继续聊天、选模型/权限/Fast 与 # 提示词，并接收指定账号的团队来信聊天。
- 手机模型列表按已授权渠道分组，自己的配对设备可在当前回复结束后接续其他渠道；携带当前 WorkStudio 聊天文本与未发送草稿，不自动传附件和工具输出。
- 增加 Fast 开关、主输入栏标记及用量提示；接续文本可展开查看，发送确认与停止恢复只比较用户自己的文字，不把历史包装放回草稿。
- Android/iOS 共用聊天输入框同步调整为上下两层：上方输入，左侧 # 提示词和权限，右侧模型与思考强度、发送/停止；选项浮层支持滑块和模型列表，取消不修改当前设置，应用成功后才更新显示。
- Codex 主题正文增大字号、行距和段落/列表间距，继续使用内置无衬线字体。
- Android/iOS 共用界面增加默认 Codex 主题、按项目分组的聊天、置顶/改名/归档操作。新聊天保留项目与模型设置，移除名称和专题选择。
- 会话中增加 # 提示词补全及明显入口，从已配对电脑读取预设，选择后填入草稿再发送；支持固定 iOS/安卓打包，结果与失败分析回到原聊天。置顶和主题保存在各自设备。
- 对话菜单增加电脑当前模型、思考强度和权限选择，以及 @ 团队成员；权限选择由电脑验证，文件外发仍须电脑确认。
- 对话菜单增加“执行 iOS 打包”，等价于发送 /打包，触发电脑配置的固定 Jenkins Job，在聊天里收到状态及构建页面链接。
- 登录页的服务器地址不再预先填团队服务器，空着，框里提示「比如 192.168.1.20:47120」：源码公开后，别人连的是自己电脑上开的中转服务。不写 `http://` 也行。
- 任务列表和任务页顶上写着任务在电脑上的哪个项目里，对话页顶上写着会话的项目；会话开在别的项目里的，任务页的会话列表里也会写出来。要电脑上的 Studio 升级到同一时间的新版才会发项目名，没升级的时候不显示。

## 0.2.0

手机上重做了一版（界面和数据都重写，连接和传文件照旧）：

- 不卡了：会话历史按会话分开存在手机上，在后台线程里存、只存变了的；打开会话先显示手机里存的，再只拉新的部分；模型一个字一个字回复时只重画正在变的那一条。连上或回到应用（隔 15 秒以上）才重新同步任务，几个任务一起拉。
- 打开应用回到上次的对话（「设置 → 打开应用时」可以关掉），返回一层是「工作台」。
- 工作台：最上面是「等你处理」（等你审批、等你回答的会话，点了直接进去），下面是任务，按最近活动排，带状态点、在跑和等你的数量、时间。配了多台电脑时顶上可以按电脑筛。
- 任务页：子代理和分支挂在主会话下面，默认收起；归档的收在最下面。新建任务、新会话都从右下角的「+」开，在底部面板里填。
- 对话页：一轮里的工具调用和思考收成一行「N 个操作 · 改了 X 个文件 · Y 个失败」，点开一条看输入、输出和改动（diff）；Markdown 完整显示（代码块整块可横向滚动、有序和嵌套列表、引用、表格、斜体、链接）；子代理一行，点了进子会话；提示、出错、上下文压缩各有简短的样子。
- 输入框从一行起，发送按钮在框里；会话在跑时出现「停止」。往上翻时右下角有「↓」，来了新消息会写「新消息」。等你审批和回答的卡片不在屏幕上时，输入框上方钉一条，点「查看」跳过去。
- 审批卡：命令用等宽字体，长的收成三行可展开，「拒绝」「允许」并排；处理过的写中文结果。
- 顶栏改成返回箭头和图标；出错和断线的提示浮在页面下方，不再把页面往下挤；电脑和配对挪进「设置」。

## 0.1.2

- 不再自动检查更新：只在「设置 → 更新」里点「检查更新」时才去问服务器（手机上的 Tailscale 不太稳，自动检查容易报错）。检查到新版本后，顶上才会提示「有新版本」。

## 0.1.1

- 能从团队服务器更新：打开应用时（之后每 6 小时回到应用时）检查一次，有新版本时顶上提示「有新版本」；「设置 → 更新」里看改动说明、下载（带进度，可以取消）并安装。下载的安装包核对过大小和校验值才交给系统安装。第一次安装要按提示允许 AMO Studio 安装应用。
- 电脑把任务授权给你自己账号的另一台设备时，手机也能看到并接着用（要电脑上的 Studio 也更新到这一版）。

## 0.1.0

- Android 远程客户端：登录团队服务器、配对自己的电脑、查看授权任务。
- 与桌面一致的新建任务和首个会话、任务下新会话、流式对话、审批、提问和中断。
- HTML、Markdown、图片和文本查看；HTML 中的内联交互与任务内文件链接。
- AMO Studio 浅色、深色和跟随系统主题，随包提供 Noto Sans SC、Noto Serif SC、JetBrains Mono 字体。
- 适配手机安全区、软键盘、横竖屏；私有草稿、账号令牌加密、历史缓存、断线恢复和授权撤回。

第一版只运行远程客户端，不包含本地模型、Focus、批注、书签、画布、Git Review 或终端。
